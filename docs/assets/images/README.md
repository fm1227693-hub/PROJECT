# `assets/images/`

Static raster assets: OG/social card, favicons, and any photographic plate you want to
use instead of a generative one.

Suggested set:

```
og.jpg            1200×630, ≤ 200 KB
favicon.svg       monogram
apple-touch-icon.png  180×180
```

Team portraits are **not** photos — they are generated abstract plates
(`painters['portrait-a'|'portrait-b'|'portrait-c']` in `js/components/generative.js`),
so no model releases or stock licences are involved. If you replace them with real
photography, record the licence and release status here.
